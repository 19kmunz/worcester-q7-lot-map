# Worcester Question 7 lot-minimum story

A scrolling, map-driven page (`index.html`) supporting a petition to set a 5,000 sq ft minimum lot size for single-family homes in Worcester's RS-10, RS-7 and RL-7 districts.

- `data/story-data.js`: the map data used by the page
- `data/*.csv`, `data/opportunity-parcels.geojson`: downloadable lot data

Parcel data: Community Scale Question 7 lots tool and MassGIS Level 3 assessor parcels (FY2026). Zoning: City of Worcester. Basemap: USGS The National Map.
