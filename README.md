# Worcester Question 7 lot-minimum petition

Static site with two maps and their data, supporting a petition to set a 5,000 sq ft minimum lot size for single-family homes in Worcester's RS-10, RS-7 and RL-7 districts.

- `map.html`: Map 1, lots that could be subdivided
- `existing-lots.html`: Map 2, homes already on lots below their district's minimum

Parcel data: Community Scale Question 7 lots tool and MassGIS Level 3 assessor parcels (FY2026). Zoning: City of Worcester. Basemap: USGS The National Map.
